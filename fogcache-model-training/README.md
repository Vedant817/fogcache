# FogCache ML

Hot-key analytics, classification and prediction models for FogCache.

## Layout

- `src/fogcache_ml/` — Python package
- `tests/` — pytest suite
- `notebooks/` — exploratory notebooks
- `models/` — trained model artifacts

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -e ".[dev]"
```
